핵심 화면 목업

비개발자가 슬라이드를 만드는 가장 단순한 흐름. 4 단계 워크플로우와 그 진입점인 홈(내 발표 자료) 으로 구성됩니다.

홈

내 발표 자료

4 단계 흐름의 진입점. 만든 자료들을 카드 그리드로 보고, "+ 새로 만들기"로 1번 화면 진입.
화면 1

AI 도구 설치 확인

Claude Code 또는 Codex가 설치/연결되어 있는지 확인. 안 되어 있으면 여기서 막힙니다.
화면 2

발표 내용 올리기

제목과 발표에 들어갈 내용을 입력하거나 파일로 올립니다.
화면 3

디자인 고르기

slides-grab이 가져온 진짜 슬라이드 견본을 카드로 보고 마음에 드는 분위기를 선택합니다.
화면 4

완성된 발표 자료 보기·수정

slides-grab이 만든 슬라이드를 미리 보고, 같은 화면에서 수정합니다.
화면 4 추가

전체 슬라이드 일괄 수정

"여백 다 맞춰줘" 같은 자연어 한 줄로 deck 전체를 일괄 수정.
화면 4 추가

내보내기 (PDF / PNG / PPTX)

완성된 deck 을 PDF · 이미지 묶음 · 파워포인트로 받기. PDF 권장, PPTX 베타.
홈 추가

라이브러리 카드 빠른 다운로드

완성된 카드의 ⬇ 버튼 → 형식 메뉴 → 카드 안에서 진행 → 자동 다운로드. 페이지 이동 없음.
화면 3.5 (신규)

outline 검토

디자인 고른 후 곧바로 슬라이드 만들지 않고, plan skill 의 outline 을 사용자에게 보여주고 직접 편집 가능.
안내 · 이 목업은 정적 HTML입니다. 실제 동작이 아닌 화면 흐름/UX 검토용이에요. 각 화면 상단의 단계 칩으로 이전·다음 화면으로 이동할 수 있습니다.
