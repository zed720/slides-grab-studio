1) 진입점 — deck 페이지 toolbar 의 ⬇ 내보내기 버튼

화면 4 (/deck/[id]) 의 메인 패널 상단 toolbar. 슬라이드가 모두 만들어진 후에만 노출 (만드는 중에는 숨김).

2) 클릭 시 모달 — 형식 선택

3가지 중 하나 선택. PDF 가 가장 안정적이라 기본 선택. 파워포인트 (PPTX) 는 베타 라벨로 안정성 안내.

이미지 묶음 (PNG)
슬라이드 한 장당 PNG 이미지 한 장. 전부 zip 으로 묶어서 받습니다. SNS 업로드, 썸네일 활용에 편해요.
파워포인트 (PPTX) 베타
파워포인트에서 다시 편집할 수 있는 파일. 아직 글자나 위치가 조금 어긋날 수 있어요. 발표용으로는 PDF 를 권합니다.
Figma Slides 용 (PPTX) 베타
Figma Slides 의 Import 메뉴로 불러와 다시 편집할 수 있는 파일. Figma 안에서 폰트가 바뀌거나 모양이 조금 어긋날 수 있어요. 일반 파워포인트가 필요하면 위의 PPTX 를 받으세요.

3) 만들기 시작 후 — 진행 / 완료 / 실패

모달은 계속 열려 있고 본문만 바뀐다. 만드는 동안 다른 슬라이드 미리보기는 그대로 가능. 사용자가 모달을 닫아도 백그라운드에서 계속 진행되고, 라이브러리 / 다시 들어와도 받을 수 있다 (작업 단위 5 — 선택).

4) 동작 메모 (디자인 결정)

  • 슬라이드가 모두 만들어진 후에만 노출. 만드는 중 / 일괄 수정 중에는 버튼이 사라진다. (반쯤 만들어진 deck 을 내보내면 혼란만 생김.)
  • 한 번에 하나만 가능. PDF 만드는 동안 같은 deck 의 PPTX 만들기 시도하면 버튼 비활성. 다른 deck 은 무관.
  • 모달을 닫아도 진행은 계속. 다시 ⬇ 내보내기 클릭하면 진행 상황 / 완료된 파일이 그대로 보임 (같은 형식 기준 마지막 시도).
  • 완료된 파일은 보관. 같은 형식으로 새로 내보내기 전까지는 다운로드 링크 유지. 새로 만들면 이전 파일은 덮어쓴다.
  • 파일 이름 은 deck 의 제목을 그대로 사용 (공백은 하이픈). 예: 2026-상반기-사업-계획.pdf
  • 이미지 묶음 (PNG) 은 zip 한 개로. 파일 이름 안에는 slide-01.png … slide-20.png.
  • Figma 용 파일 은 일반 PPTX 와 구분 위해 끝에 -figma.pptx 붙임. 예: 2026-상반기-사업-계획-figma.pptx
  • 세부 옵션 없음. 해상도/모드 같은 건 안 좋은 디폴트 (4K 화질, 이미지 캡처) 만 사용해서 결정 피로 0. 필요해지면 "고급 옵션" 으로 나중에 추가.
  • 실패해도 사용자 워크플로우는 막지 않는다. 다시 시도 / 다른 형식 선택 / 닫기 셋 다 가능.
