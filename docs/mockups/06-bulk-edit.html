전체 슬라이드 일괄 수정 (화면 4 의 추가 기능)

1) 진입점 — deck 페이지 toolbar 의 ✨ 전체 수정 버튼

화면 4 (/deck/[id]) 의 메인 패널 상단 toolbar. 미리보기 모드일 때만 노출.

2026년 상반기 사업 계획

2) 클릭 시 모달

자연어로 deck 전체 슬라이드에 일괄 적용할 지시를 입력. AI 가 백그라운드에서 모든 슬라이드 HTML 을 수정.

✨ 전체 슬라이드 일괄 수정 ✕
예시
  • "여백을 모든 슬라이드에서 동일하게 맞춰줘"
  • "제목 글자 크기를 조금 더 크게"
  • "전체 톤을 더 친근하게"
  • "메인 색깔을 모두 #3b82f6 (파랑) 으로 통일"
  • "각 슬라이드 하단 footer 글자 크기 절반으로"
💡 슬라이드 수와 inline 구조 (color/굵기 등) 는 보존됩니다. 새 슬라이드 추가/삭제는 안 해요.

3) 진행 중 — making-bar 의 라벨이 일괄 수정 중으로 바뀜

모달 닫힌 후 deck 페이지 상단의 making-bar 가 단계 라벨을 "전체 슬라이드 수정 중…" 으로 표시. 사용자는 그동안 다른 슬라이드 미리보기 가능.
