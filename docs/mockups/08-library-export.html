2) 동작 메모 (디자인 결정)

  • 완성된 카드 (status === "ready") 만 ⬇ 버튼 노출. 만드는 중 / 실패 카드는 버튼 숨김.
  • 카드 본체 클릭 동작은 그대로 (deck 페이지로 이동). ⬇ 버튼 클릭만 별개로 처리 (이벤트 전파 stop).
  • 형식 메뉴는 4 옵션 — deck 페이지의 ExportModal 과 같은 라벨/순서. PNG 는 같은 "준비 중" 잠금.
  • 같은 deck 에 한 번에 하나 — 이미 진행 중인 export 가 있으면 그 카드의 ⬇ 버튼은 자동으로 overlay (진행 중) 상태. 다른 카드는 무관.
  • completed 시 자동 다운로드 trigger — `` 를 프로그램으로 click(). 사용자가 한 번 더 받고 싶으면 "다시 받기" 버튼.
  • overlay 닫기 — completed / failed 상태에서 카드 어디를 클릭하든 overlay 사라지고 ① 기본 상태로. (deck 페이지 이동은 별도 액션 시.)
  • 모든 진행/완료/실패는 카드 안에서 끝남. deck 페이지 안 들어가도 됨. 단, 같은 deck 의 ExportModal 폴링과 충돌 없음 — 둘 다 같은 jobId 기준이고 server 가 한 deck 1 job 제한.
